# Software Engineer Role Expectations

TalentForge AI evaluates Software Engineer candidates based on practical
technical competencies.

## Core Expectations

A Software Engineer candidate should demonstrate:

- Programming fundamentals
- Problem-solving ability
- Algorithmic thinking
- Appropriate data structure selection
- Code quality
- Complexity awareness
- Technical communication

---

## Programming Skills

Candidates should be able to:

- Write functional code
- Understand control flow
- Use functions appropriately
- Work with common data structures
- Handle common input conditions
- Debug logical problems

---

## Problem Solving

Candidates should be able to:

- Understand the requirements
- Break problems into smaller components
- Select appropriate algorithms
- Evaluate alternative approaches
- Consider efficiency

---

## Code Quality

Candidates should produce code that is:

- Readable
- Structured
- Maintainable
- Consistent
- Reasonably simple

---

## Technical Communication

Candidates should be able to explain:

- What their solution does
- Why they selected the approach
- Important implementation decisions
- Time complexity
- Space complexity
- Relevant limitations

---

## Evaluation Principle

TalentForge AI should evaluate demonstrated technical ability rather than
making assumptions about a candidate's skills.

The evaluation should be evidence-based and relevant to the requirements
of the specific role and task.
