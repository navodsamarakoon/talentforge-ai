# TalentForge Evaluation Criteria

TalentForge AI evaluates technical candidates using five primary criteria.

## 1. Correctness

Correctness measures whether the candidate's solution correctly solves
the given technical task.

The evaluation should consider:

- Test results
- Expected behavior
- Handling of valid inputs
- Handling of important edge cases
- Logical correctness of the implementation

A candidate should not receive a high correctness score when the solution
only works for a small subset of possible inputs.

---

## 2. Problem Solving

Problem Solving measures the candidate's ability to understand a problem
and develop an appropriate algorithmic solution.

The evaluation should consider:

- Understanding of the problem
- Choice of algorithm
- Choice of data structures
- Logical reasoning
- Ability to identify constraints
- Ability to improve an inefficient approach

---

## 3. Code Quality

Code Quality measures how clearly and maintainably the candidate
implements the solution.

The evaluation should consider:

- Readability
- Code structure
- Meaningful variable names
- Appropriate use of programming constructs
- Maintainability
- Avoidance of unnecessary complexity
- Consistent coding practices

---

## 4. Efficiency

Efficiency measures the computational performance of the solution.

The evaluation should consider:

- Time complexity
- Space complexity
- Choice of algorithm
- Choice of data structures
- Scalability for larger inputs

A correct solution can still receive a lower efficiency score if
a significantly better algorithm exists.

---

## 5. Explanation

Explanation measures how clearly the candidate communicates their
technical reasoning.

The evaluation should consider:

- Understanding of the solution
- Explanation of the algorithm
- Explanation of important decisions
- Time complexity explanation
- Space complexity explanation
- Awareness of limitations or edge cases
