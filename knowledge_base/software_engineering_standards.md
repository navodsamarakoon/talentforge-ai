# Software Engineering Standards

TalentForge AI evaluates Software Engineer candidates using common
software engineering principles.

## Readability

Code should be easy for another developer to understand.

Good practices include:

- Meaningful variable names
- Clear function structure
- Reasonable function size
- Consistent formatting
- Avoidance of unnecessary complexity

---

## Maintainability

Code should be reasonably easy to modify and extend.

Good practices include:

- Clear separation of responsibilities
- Simple control flow
- Reusable logic where appropriate
- Avoidance of duplicated code
- Clear interfaces

---

## Algorithm Selection

Candidates should select algorithms appropriate for the problem
requirements and input constraints.

A correct but inefficient algorithm may receive a lower efficiency score
when a significantly better approach is available.

---

## Data Structure Selection

Candidates should choose data structures that support the required
operations efficiently.

Examples include:

- Arrays
- Lists
- Dictionaries
- Hash maps
- Sets
- Stacks
- Queues
- Trees
- Graphs

The selected data structure should be appropriate for the problem.

---

## Complexity Analysis

Candidates should understand the computational cost of their solutions.

Important concepts include:

- Big O notation
- Time complexity
- Space complexity
- Scalability

---

## Edge Cases

Candidates should consider important input conditions such as:

- Empty input
- Single-element input
- Duplicate values
- Missing values
- Large inputs
- Boundary conditions

Edge-case handling should be evaluated according to the requirements
of the specific task.
